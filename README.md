# 🎬 Movie Website

A responsive web app to search and browse movies using OMDB API. Built with React.js

## ✨ Features
- **Search Movies**: Find any movie by name instantly
- **Movie Details**: View poster, rating, plot, cast, release date
- **Trending Section**: Browse popular movies on homepage
- **Responsive UI**: Works perfectly on mobile and desktop

## 🛠️ Tech Stack
**Frontend**: React.js, CSS3, JavaScript ES6  
**API**: OMDB API  
**Tools**: Git, GitHub
